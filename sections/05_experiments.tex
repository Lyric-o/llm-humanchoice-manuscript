\section{Experiments}
\label{sec:experiments}

All experiments reuse the human-labeled comparison dataset provided for this project. We run the
judge on every comparison and reveal $n$ human labels, with $n/N\in\{1,2,5,10,20\}\%$. The
remaining labels, on a test set split by prompt, are used only for evaluation.

\paragraph{E1: Estimating human preferences.}
We compare \dfsp{} with the following baselines:
\begin{itemize}
  \item the raw judge;
  \item a human-only estimator;
  \item scalar recalibration of $p_J$ (Platt, isotonic);
  \item the linear map of \citet{vandenburg2025aligning};
  \item a nonlinear calibrator (GAM or boosted trees) on the same judge summaries;
  \item \sfsp.
\end{itemize}
Metrics are Brier score, log-loss and calibration error, reported against the number of revealed
labels. Ablations use only tie mass or only order inconsistency, to see which part of the judge
distribution helps.

\paragraph{E2: Does the judge distribution add information?}
We estimate and test the variable importance $G$ of $(t_J,o_J)$ given $p_J$
\citep{williamson2023general}. We first check the test's size and power in a simulation where $G$ is
known.

\paragraph{E3: Label acquisition.}
We compare the design of Section~\ref{sec:acquisition} with random sampling, judge-uncertainty
sampling, Fisher-information selection \citep{shen2025active} and disagreement-based correction
\citep{xu2025rlthf}. We do this first on synthetic data with known functions, then on the real data.

\paragraph{E4: Robustness to a poor judge.}
We corrupt the judge in several ways: bias, overconfidence, reversal in part of the space, and added
noise. We check that \dfsp{} reduces its reliance on the judge and approaches the human-only
estimator.

\paragraph{E5: Post-training.}
We fine-tune a small open-weight model with LoRA \citep{hu2022lora}. The arms are:
\begin{itemize}
  \item DPO on the $n$ human labels only;
  \item DPO on hard judge labels;
  \item soft DPO and GAPO \citep{furuta2024gapo} with raw judge probabilities;
  \item soft DPO with linear-map targets;
  \item \fsppo{} with \dfsp{} targets;
  \item DPO on all human labels, as a reference.
\end{itemize}
Evaluation has three parts:
\begin{enumerate}
  \item held-out human preference log-loss of the policy's implicit preference $\sigma(d_\vartheta)$,
        which is the quantity bounded in Proposition~\ref{prop:bridge};
  \item win rate against $\pi_{\mathrm{ref}}$, scored by a reward model trained on all human labels
        \citep{gao2023scaling} and by an independent LLM judge;
  \item KL divergence to $\pi_{\mathrm{ref}}$ and response length.
\end{enumerate}
The main plot shows policy quality against the number of human labels.
