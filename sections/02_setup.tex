\section{Setup}
\label{sec:setup}

\paragraph{Data.}
Each comparison is $X=(x,y_A,y_B)$: a prompt $x$ and two responses. The human label $Y\in\{0,1\}$
equals $1$ if $y_A$ is preferred. We use an existing dataset in which every comparison has a human
label. The judge is run on all comparisons. Only $n$ human labels, indexed by $\cI_n$, are used for
estimation. A test set, split by prompt, is held out for evaluation.

\paragraph{Judge features.}
The judge chooses one of five labels, $\{A\gg B,\ A>B,\ \text{tie},\ B>A,\ B\gg A\}$. We record the
label probabilities from its output logits twice: once with $y_A$ shown first ($\QJ^{AB}$) and once
with the order reversed ($\QJ^{BA}$). Let $w(Q)=Q(A\gg B)+Q(A>B)+\tfrac12Q(\text{tie})$. Each
comparison is described by three features:
\begin{align*}
  p_J&=\tfrac12\{w(\QJ^{AB})+w(\QJ^{BA})\} && \text{(win probability)},\\
  t_J&=\tfrac12\{\QJ^{AB}(\text{tie})+\QJ^{BA}(\text{tie})\} && \text{(tie probability)},\\
  o_J&=|w(\QJ^{AB})-w(\QJ^{BA})| && \text{(order dependence)}.
\end{align*}
We write $Z=(p_J,t_J,o_J)$. The features satisfy $t_J\le2\min(p_J,1-p_J)$,
$o_J\le2\min(p_J,1-p_J)$ and $t_J+o_J\le1$, so $Z$ takes values in a polytope $\cZ\subset[0,1]^3$.
If the data contain task categories, all estimation is done separately within each category.

\paragraph{Targets and error.}
Let $p_X=P(Y=1\mid X)$ be the human preference probability of a comparison, and
\[
  p_H(z)=P(Y=1\mid Z=z)=\E(p_X\mid Z=z)
\]
its best approximation based on the judge features. For an estimator $\hat p$ we use
\[
  R(\hat p)=\E\{\hat p(Z)-p_H(Z)\}^2,\qquad
  R_X(\hat p)=\E\{\hat p(Z)-p_X\}^2=R(\hat p)+\E\{p_H(Z)-p_X\}^2 .
\]
The last term does not depend on the estimator: it is the part of human preference that the judge
features cannot explain. On held-out data with one label per comparison, the Brier score
$\E\{Y-\hat p(Z)\}^2$ equals $R_X(\hat p)$ plus a constant, so estimators can be compared directly.
